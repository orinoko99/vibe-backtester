# Описание тестов

Тесты пишутся на `pytest`. Запуск:
```
pytest tests/ -v
```

Для каждого этапа roadmap пишутся тесты, покрывающие:
- Основной функционал (happy path)
- Граничные случаи (пустые данные, некорректные входные)
- Обработку ошибок

Тесты хранятся в `tests/` и в `tests.json` для отслеживания.
