сделать приложение на python которое будет бектестером для стратегий в т.ч. тестирование портфелей инструментов. также будет возможность вывести график со свечками, с возможностью добавлять несколько торговых инструментов на этот график (свечи, объем, volume profile, рисование на графике, текстовые метки, графические фигуры), график интерактивный (zoom in/out колесиком мышки, перемещение графика, растяжение/сжатие графика по вертикали и отдельно по горизонтали - мышкой кликнуть и тянуть по шкалам). Есть возвожность выбора торгового инструмента, выбор таймфрейма, добавление инструментов и инлдикаторов на график.

Загрузка данных - данные загружаются скользящим окном, которое движется вместе с видимо областью. Окно больше видимой области в 5 раз. По мере движения окна - данные которые в него попадают - ну в смысле которые не загружены - загружаются, те, которые уже устарели - выгружаются. Т.е.грузится только объем данных который виден пользователю + 5 объемов на экрана скаждой стороны от текущей видимой области. также, данные динамически подгружаются, если видимая область сдвигается и старые освобождаются из памяти.

данные со свечами (1 минутными) есть в нескольких базах данных sqlite: 
фючерсы:
D:\_MARKET_TICKDATA\QUIK_DATA\allCandlesFutures.db,
D:\_MARKET_TICKDATA\QUIK_DATA\allCandlesFutures_2020.db,
D:\_MARKET_TICKDATA\QUIK_DATA\allCandlesFutures_2023.db,

акции:
D:\_MARKET_TICKDATA\QUIK_DATA\allCandlesShares.db,
D:\_MARKET_TICKDATA\QUIK_DATA\allCandlesShares_2023.db

структура баз данных:
CREATE TABLE 'AAH6_M1'('ID' INTEGER PRIMARY KEY, 'Date' TEXT, 'SecCode' TEXT, 'ClassCode' TEXT, 'O' TEXT, 'H' TEXT, 'L' TEXT, 'C' TEXT, 'V' INTEGER, 'OpenInterest' INTEGER)

'O' - open,
'H' - close, 
'L' - low, 
'C' - close, 
'V' - volume, 
'OpenInterest' - кол-во открытых позиций

таблиц типа 'AAH6_M1' в базах данных (в каждой) много - это все торговые инструменты, их данные.
