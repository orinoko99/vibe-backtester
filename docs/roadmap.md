# Roadmap — План разработки backtester

## Current stage: Этап 1.1 (инициализация проекта)

- [ ] **Этап 1.1** — Инициализация проекта: установка зависимостей (PySide6, polars, lightweight-charts-python), создание main.py, run_backtester.bat, README + тест запуска приложения
- [ ] **Этап 1.2** — Модуль config.py: пути к БД, настройки по умолчанию + тесты
- [ ] **Этап 2.1** — Модуль data/models.py: Pydantic-модели свечи, инструмента + тесты
- [ ] **Этап 2.2** — Модуль data/database.py: подключение к SQLite, получение списка таблиц (инструментов), чтение свечей по SecCode и диапазону дат + тесты
- [ ] **Этап 2.3** — Модуль data/loader.py: динамическая загрузка с пагинацией (видимая область ± 2 экрана) + тесты
- [ ] **Этап 3.1** — GUI: главное окно PySide6 с placeholder + тест окна
- [ ] **Этап 3.2** — GUI: виджет графика на lightweight-charts-python, отображение свечей + тест рендера
- [ ] **Этап 3.3** — GUI: интерактивность (zoom колёсиком, pan, растяжение по осям) + тесты
- [ ] **Этап 3.4** — GUI: панель выбора инструментов и таймфреймов + тесты
- [ ] **Этап 3.5** — GUI: отображение объёма и volume profile + тесты
- [ ] **Этап 3.6** — GUI: добавление нескольких инструментов на один график + тесты
- [ ] **Этап 3.7** — GUI: рисование на графике, текстовые метки, фигуры + тесты
- [ ] **Этап 3.8** — GUI: панель добавления индикаторов + тесты
- [ ] **Этап 4.1** — Бэктестинг: базовая стратегия (strategy.py) + тесты
- [ ] **Этап 4.2** — Бэктестинг: ядро (engine.py) + тесты
- [ ] **Этап 4.3** — Бэктестинг: портфельное тестирование (portfolio.py) + тесты
