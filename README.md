# Vibe Backtester

Бэктестер торговых стратегий с интерактивными графиками и поддержкой портфелей инструментов.

## Возможности

- Загрузка минутных свечных данных из SQLite баз данных (фьючерсы и акции)
- Тестирование торговых стратегий на исторических данных
- Тестирование портфелей инструментов
- Интерактивный график со свечами (zoom, pan, масштабирование)
- Volume Profile
- Рисование на графике (линии, текстовые метки, фигуры)
- Добавление нескольких инструментов на один график
- Выбор торгового инструмента и таймфрейма
- Поддержка индикаторов

## Установка

```bash
# Клонировать репозиторий
git clone https://github.com/orinoko99/vibe-backtester.git
cd vibe-backtester

# Создать виртуальное окружение
python -m venv venv
venv\Scripts\activate  # Windows
# source venv/bin/activate  # Linux/Mac

# Установить зависимости
pip install -r requirements.txt
```

## Запуск

```bash
python src/main.py
```

## Источники данных

Проект использует минутные свечные данные из SQLite баз данных QUIK.
